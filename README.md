# Qwen 3.8 Vision OCR
### Experimental AI Engineering Project: OCR Application based on Groq Qwen 3.8 27B and Streamlit for the web-based UI

## Install Dependency
```powershell
# Install dependencies
pip install streamlit groq pillow python-dotenv
```

## Setup API Key
```powershell
# Add your Groq API Key inside .env file
GROQ_API_KEY=your_groq_api_key_here
```

## How to run app
```
streamlit run app.py
```
